# 记忆大师 · Memory Master

一个网页版的竞技记忆训练工具，复刻**世界记忆锦标赛（World Memory Championships）**官方训练 App 的核心功能。

官方 App「脑力大师」由世界记忆运动理事会推出，但只提供 Android / 平板 / 电脑版本 —— iOS 版从 2022 年发布起就一直写着"敬请期待"。这个项目把它搬进浏览器：**iPhone 上打开 Safari 就能用，数据只存在你自己的设备里。**

---

## 为什么是网页

| | 官方 App | 这个项目 |
|---|---|---|
| iOS | 无 | 有（任何现代浏览器） |
| 安装 | 需下载 APK | 打开链接即可，可添加到主屏幕 |
| 账号 | 需注册 | 无账号、无登录 |
| 数据 | 上传服务器 | 仅存本地 localStorage |
| 网络 | 需要 | 首次加载后可离线使用 |

## 十大正式项目

全部按赛事规则实现"记忆阶段 → 回忆阶段"两段式计时与判分。

### 数字

- **随机数字** — 长时记忆的硬指标，可选 100 / 400 / 1000 位
- **快速数字** — 5 分钟约 200 位，考验编码的即时提取速度
- **二进制数字** — 0 与 1 的转译训练，标准赛制 900 位
- **听记数字** — 每秒朗读 1 个数字，只能用耳朵记

### 牌与图形

- **随机扑克** — 多副牌的长时记忆，标准赛制 5 副 260 张
- **快速扑克** — 5 分钟记忆一副打乱的牌
- **抽象图形** — 图形打乱后写出各自的原编号

### 语义记忆

- **随机词语** — 故事法的主战场，20 / 40 / 100 / 200 词
- **人名头像** — 看脸写名，最贴近日常的一项
- **虚拟历史事件** — 虚构事件 + 年份，无法依靠真实历史知识作弊

## 使用

### 直接打开

下载后双击 `index.html` 即可，无需构建、无需服务器。

### 部署到 GitHub Pages

```
Settings → Pages → Source: Deploy from a branch → main / (root)
```

之后可以通过 `https://<用户名>.github.io/memory-master/` 访问。

在 iPhone 上打开后，点击分享 → "添加到主屏幕"，就能像原生 App 一样全屏运行。

### 深链接

`?g=<项目 id>` 可以直接打开某个项目：

```
index.html?g=speedcards
```

项目 id：`digits` `speednum` `binary` `spoken` `cards` `speedcards` `abstract` `words` `faces` `dates`

## 数据

所有成绩保存在浏览器的 `localStorage`（键名 `memorymaster.v1`）。

- 不会上传到任何服务器
- 换设备、清理浏览器数据、使用无痕模式都会丢失
- 设置里可以**导出 JSON 备份**，在另一台设备上导入即可迁移
- 导出文件就是明文 JSON，可以自己处理

---

## 判分规则

| 项目 | 计分方式 |
|---|---|
| 随机数字 / 快速数字 / 二进制 | 每行完全正确才计分，1 位 = 1 分 |
| 扑克类 | 按位置逐张比对，统计正确张数与最长连续段 |
| 随机词语 / 人名头像 / 虚拟事件 | 每项精确匹配得 1 分 |
| 抽象图形 | 编号写对得 1 分 |
| 听记数字 | 逐位比对，另统计从头开始的连续正确位数 |

> 这是训练工具，不是赛事裁判系统。部分项目的官方细则（如时间奖励、并列判定）做了简化。

## 技术

纯静态，零依赖，无构建步骤：

```
index.html
css/style.css
js/
  utils.js      工具函数
  store.js      localStorage 封装
  engine.js     训练流程引擎（阶段、计时、结算）
  app.js        路由、首页、记录、设置
  games/        十个项目，各自实现 generate / memo / recall / judge
```

- 原生 JS（ES5 风格 IIFE，无框架）
- 头像与抽象图形由 SVG 程序化生成，不依赖任何图片资源
- 听记数字使用 Web Speech API
- 计时基于 `performance.now()`，切到后台不会失真
